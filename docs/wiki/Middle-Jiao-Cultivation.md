# 中焦周天、外壁与真炁

数值集中在 `HumanCultivationNumbers`，本轮均为可调占位。人体策略只生成 Framework 的 `BodyActivity`，真元、动作、伤势、境界及 `human:cultivation` 进度都由同一身体保存。没有旧存档迁移。

## 周天与操作

右键使用《炁脉札记》与中焦残卷后即可从修炼页打开独立“中焦”弹窗，无须看完。中焦八脉全开且完好后开始。先等已有普通在途抵达，接管八脉扩散，从库存最多的环上经脉取得最多10元，原位预约返回体积。停止时归还唯一在途货物。闭环连接2.4米加脉内6.6米，共9米；1元/秒下10元第一圈基础19秒，整圈只计一次批量吞吐。后续圈按剩余批量重算；操作停顿另计，普通单段公式不变。

按住G增推力、松开减速。手足端安全带0.8～1.2，其余0.65～1.35；过慢每秒逸散0.5%，过猛通过健康接口渗漏并停机。脑1W、注意组织0.5W持续支出，沿用既有疲劳与空闲恢复。

四个关口按真实人中/中焦路线设置。服务器自然呼吸周期8秒，吸呼各4秒；呼气阶段在收缩环到点±450ms按空格。目标圈固定，指示圈收缩到目标处；绿色表示可以按空格，红色表示未到或错过。失误撞回500ms进度，额外消耗2J精力；不按则等下个时窗。客户端读取服务端 `gate_window_millis` 插值提示，最终仍按服务端时刻判定，不回拨客户端时间。

右键使用中焦残卷即可勾选“自动”，不要求看完或任何手动成功次数。自动持续消耗脑耐力1W，不消耗或占用注意组织；有效脑耐力低于80%即停止并归还在途，需要休息后手动重启。命名占位 `AUTOMATIC_MIN_STAMINA_RATIO=0.8`。沿用 `AUTOMATIC_EFFICIENCY=0.5`，手动每圈四次成功可到1。运行中切换模式保留当前圈货物和关口。主动外壁动员是独立操作，仍耗脾耐力与精力，包括自动周天期间的突破动员。

`CultivationState` 会把当前有效脑耐力比例、自动停止线、自动效率、呼吸周期、呼气起点和关口收缩时长随身体快照提供给客户端。客户端只按这些字段绘制提示，空格命中与自动停止仍由服务器判定。

每圈 `x=log10(ρ/0.01)`，`Δx=0.2(1-0.7x)×效率`。密度封顶0.099，以实际 `log10(新ρ/旧ρ)` 计算数量保留 `10^(-0.66Δx)`。到顶继续运行不再扣提纯损耗，损耗回环境。突破成功前不能转0.1。

## 脾与外壁

内腔体积占用≥90%时，左右脾经最多取0.1元进脾，复用2秒器官加工，产出80%，保留实际密度，损耗回环境。产物按构型顺序填各脉外壁，空间不足留在脾缓存。外壁不随开脉扩充。

内腔<50%时以0.02元/秒自行提取；主动动员1元/秒，脾2W、注意组织0.5W。回本脉内腔，受容量预约限制。脾耐力600J、最大20W、恢复半衰期30秒；失能停止加工/动员，主动过载通过健康接口伤脾0.1HP并停止。这些参数均为占位。

单项转移不足 `MIN_TRANSFER_QI=1e-8` 元时保留在原账户，等待后续同类库存合并；不删除尾差，也不计作已转移或环境损耗。储备调度采用同一规则，避免极小浮点残量导致持续空转或账本数值拒绝。

## 突破真炁

启动需要八脉全开、周天运行、**内腔加本次周天在途**中ρ≥0.09候选至少50元、外壁至少60元。外壁60元只查启动。之后每个整数秒检查并消耗1元外壁燃料，需保持主动动员；期间关闭普通外壁提取。

连续60秒。候选不足、断供、周天或动员中断、疲劳停机均清零连续时间，已耗燃料不退。成功变为真炁，内腔和本次周天在途的候选转为0.1，其他游离态保留混相。既有真炁层八脉随境界解锁，开脉每条仍+1625体积。

关闭中焦弹窗、断线或残卷撤权立即停止主动活动、归还在途、解除占用。重连不补算离线提纯或相变。脾加工原料保留在框架账户。

## OP 命令与验证

权限等级2，可从控制台指定玩家：

```text
/meridian opening complete <玩家> <经脉ID|all>
/meridian purity set <玩家> lumen <经脉ID|all> <数量> <密度>
/meridian purity set <玩家> wall <经脉ID|all> <数量> <密度>
```

完成 `all` 指全部现存经脉；只测游炁应逐条指定八脉。已开经脉不重复扩容。真元 `all` 的数量是全身总量，按扣除在途预约后的可用体积分配，0可清空；不能挤超体积或在途预约。调试不授予残卷或熟练度。
