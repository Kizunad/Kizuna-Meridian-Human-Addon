# Kizuna's Meridian Human Addon

这是独立 Git 仓库的人体附属，依赖 Kizuna's Meridian Mod Framework。人体定义与固有生理配方属于本仓库，唯一身体、寿命和真元状态仍由经脉框架的权威执行方持有。

当前已实现：

- `human` 命名空间的 `AddonBundle`，包括人体模板、类型符号和五种肺炼化配方。
- 可信宿主使用的出生候选：健康身体、醒灵、每条经脉少量游离态真元、全部未开拓。
- 客户端只依赖框架生成消息的摄入、配方启动、运输和结算请求。
- 真实 Java 参考处理器上的环境扣账 → 肺缓存 → 加工 → 在途 → 肺经 → 全身自然储存。
- 可选 Fabric 宿主按权威吐纳状态播放/停止 Animations `meditate`，沿动画侧 Protobuf 同步外世界玩家。
- JAR 内 Protobuf 内容、下游附属前置依赖、失败无副作用、重试、恢复与守恒整体回归。
- 客户端 Protobuf 展示资源：以 Blockbench 拼装文件为编辑源，提供表层、骨架、19 块肌肉、15 个器官和 36 条经脉及 UV 贴图。

目前包括 Java 17 内容库、内存聚气演示和可选 `fabric/` 玩家宿主。Fabric 1.20.1 绑定实际行走/疾跑与手动吐纳，使用框架动作与疲劳结算，从主世界共享灵气区域摄入，保存玩家身体和环境账户，并向可选 UI 推送状态。Bong 装配、区域间扩散以及原版生命/伤害映射仍待后续接入。

## 接下来的边界

聚气、储存与开脉已经接通。框架提供通用算子、调用门槛与唯一账本，人体附属配置入口和数值，通过权威命令启动和暂停，不直接修改开拓状态。

肺经纳入后全身自然扩散及可选打坐动画已接入。[修炼与开脉](Cultivation.md)已支持 80% 启动、专用引导、目标至少 22 元增压、首条组合计 22 元且后续每条增加 16.75＋已开条数、递增维持、独立脑耐力和精力、真实摄入窗口及每条一次增加 16.25 元容量。醒灵先开放左右肺、大肠手经与脾、胃足经，共八条，覆盖四肢，完成后稳定容量为 150 元；经脉逐境解锁至通灵展示当前完整主干。局部细支独立模块、相变升境与长期数值平衡仍待完成。

肌肉增益、功法学习、器官改造及 3D 内景分别走各自模块。当前肺配方是固定 20% 小批次，尚无按器官实例改造参数计算的动态效率。既有身体恢复使用保存的实际构型，不能因为人体模板更新而重生或补满资源。
